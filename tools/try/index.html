dialogue.txt — make and check your file

A publisher's own published, standing, talk-only consent to be contacted by any reader, including AI systems. The publisher is a person or an organisation. A first message only proposes; the publisher's reply creates the channel.

Everything happens in your browser. Nothing you type is sent anywhere.

Make your file

Publish a file only for yourself, as an adult, or for an organisation you are authorised to speak for. Never for a child or for another person.

Organisations use the "we" wording of the short text; the first line is the same for everyone.

Messages must carry this reference in the subject or first line. Set a filter in your mailbox that keeps only mail containing it. Change it any time; old harvested lists stop working. It is public, not a password.

A label is a sign, not a fence: other questions stay allowed.
